## 📚 Operating Systems I
* **Project Name:** Concurrent Tetris
* **Description:** A competitive two-player Tetris rendered in the terminal with `ncurses`, built around a fully concurrent architecture instead of a single sequential game loop. Four independent threads decouple blocking operations from rendering — a producer input thread, an observer render thread, and one logic thread per player — so one player's processing or input latency never stalls the opponent's animation. Clearing two or more lines at once sends garbage rows to the opponent's board.
* **Techniques:** Multithreading, Producer-Consumer Pattern, Critical Sections & Mutual Exclusion, C++20 Semaphores (`binary_semaphore`, `counting_semaphore`), Race Condition Prevention, Thread-Safe Queues, Real-Time Terminal Rendering.
* **Stack:** `C++` (C++20), `ncurses`, `CMake`
* **Repository:**
